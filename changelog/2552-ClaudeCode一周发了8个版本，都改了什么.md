# Claude Code一周发了8个版本，都改了什么

> 原文链接：[https://www.b2cc.com.cn/claudedt/2552](https://www.b2cc.com.cn/claudedt/2552)

<p>一周连发八个版本，朋友瞅见 Claude Code 又更新时，丢来这么一句吐槽：谁跟得上。跟不跟得上另说，把 8 月 17 日到 23 日这八份 changelog 连起来读一遍，读出的故事跟表面完全不同：八份里有两版只用一行&#8221;Bug fixes and reliability improvements&#8221;交差，但叠在一起的信息量远超预期。版本号从 v2.1.234 滚到 v2.1.241，平均一天不止一版。没有惊天动地的大功能，更像一场持续的自我体检，查出来的毛病，用过的人多半眼熟。</p>
<figure><img decoding="async" src="https://cdn.laoshoucun.com/web/claude/2026/08/20260824223305_827381.png" alt="Claude Code 一周八个版本更新概念图" style="max-width:100%;height:auto"></figure>
<h2>三处变化，普通用户立刻感知得到</h2>
<p>2.1.234 送来最实用的一条：用量额度重置之后，会话自动接着跑，不必手动重开，熬过月底额度清零再干等重置的人最懂这份省心。2.1.237 的 Concise 输出风格排第二：勾上之后 Claude 直接给结果，&#8221;好的，我来帮您&#8221;那套客套全数跳过，效率提升肉眼可见。第三处是 2.1.235 的拼写检查：输入框里打错的词实时划线提示，底层调的是系统现成的 aspell 或 hunspell，额外额度一点不占。</p>
<h2>Windows 用户这回被想起了</h2>
<p>更新名单里终于添上了 Windows 用户的名字。跨会话消息（SendMessage）补齐 Windows 支持，不同机器上的 Claude Code 会话从此可以互相打招呼，macOS 和 Linux 早就有的能力，这次算是补齐对齐。安全侧另压着一条硬货：远程文件读取，会话恢复，CLAUDE.md 引用，统一拒绝 Windows NT 命名空间路径，堵的正是 NTLM 凭据泄露那个方向的口子。</p>
<p>性能修补同样没停。2.1.238 治好了长会话无限吃内存，子代理的工具结果一离开显示窗口就释放，习惯挂一整晚不关电脑的老用户体感最直接。2.1.234 把内置 claude-api 技能的上下文成本从二十万 token 压到两万五，一刀砍掉八成多。2.1.239 属于账单面的修正：Bedrock 代理环境下流式请求被悄悄降级成非流式、每轮重复计费的 bug 修了，成本估算也补上了美国本地推理的 1.1 倍溢价。跟钱挂钩的修正，从来不缺受众。</p>
<h2>小修小补里，藏着产品态度</h2>
<p>翻 changelog 有个隐秘的乐趣：看这个团队把什么当回事。&#8221;vim 模式下按 Esc 会清空输入框&#8221;，修了。&#8221;鼠标点终端窗口想聚焦，却误触权限弹窗的按钮&#8221;，修了。&#8221;会话标题以斜杠开头导致无法寻址&#8221;，也修了。边角问题单拎出来个个不起眼，但每一个背后，都是某位真实用户被硌了一下的位置。日更八版的节奏底下没有大动作，大东西早在 auto mode、跨会话协作那些版本里铺垫完毕，这一周干的活，是给地基找裂缝。</p>
<h2>别观望，直接更</h2>
<p>要我说，直接更到最新。内存泄漏和计费都是越早处理越好的类型，升级本身又不含破坏性变更。老用户终端里跑一句更新命令就行。新机器起步走<a href="https://www.b2cc.com.cn/install" target="_blank" rel="noopener">安装包</a>。版本差异翻<a href="https://www.b2cc.com.cn/claudedt" target="_blank" rel="noopener">更新</a>记录自然明白。至于下一个让行业抖三抖的大功能，按这个团队的习惯，大概率已经在某条没写进 changelog 的分支上跑着了。</p>
