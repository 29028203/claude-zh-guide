# GitHub 上那个画架构图的技能 Archify，收藏到 19.5K 了

> 原文链接：[https://www.b2cc.com.cn/chajian/2611](https://www.b2cc.com.cn/chajian/2611)

<p>GitHub 上那个画架构图的技能 Archify，这两周收藏涨到 19.5K。它火起来不奇怪，画架构图这活，AI 一直没真正接住。</p>
<p><img decoding="async" src="https://cdn.laoshoucun.com/web/claude/2026/09/20260904191104_458377.png" alt="Archify架构图技能"></p>
<p>做过方案的人都知道，真要交一张系统架构图时有多磨人。让 AI 直接画，它没读过项目代码，画出来全是想当然的模块和箭头，你盯着图挑不出毛病，可拿到评审会上，别人一问这个服务跟那个服务怎么连的，你就得当场圆场。自己画吧，得先把整个项目啃一遍，接口怎么调、数据在哪落地，理清楚了，图也差不多能出来了，可半天时间也搭进去了。</p>
<p>Archify 把最磨人的这一段接了过去。装进 <a href="https://www.b2cc.com.cn/chajian" target="_blank" rel="noopener">Claude Code</a>，你只管跟它说，看下支付这块的代码，画张架构图。剩下的事它自己来，把项目读一遍，理清模块之间的调用关系，出图之前还会回头问你，比如这个定时任务算不算独立模块，你点头它才往下画。它要是哪段代码没看懂，会追着问，不用你从头给它讲业务。</p>
<p>想用上它，动作不多。从 GitHub 仓库把技能目录拉下来，放进 Claude Code 认得到的 skills 目录就行，新版也支持走插件市场装。装完在对话里正常说需求就触发。Cursor、Claude Code、Codex CLI 这些主流工具都认它，OpenCode、Raven 这类小众工具也能用。</p>
<p>收藏高是一回事，合不合自己的手是另一回事。第三方技能质量参差，装之前先翻翻仓库，看最近有没有在维护、Issues 里都在报什么问题。真要用，拿手头项目先跑一轮，图出来合不合用，比看 star 数实在得多。想试的，现在就装一个，丢个自己的项目进去，几分钟就能见分晓。</p>
